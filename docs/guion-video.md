# Guion de video demostrativo

Duración objetivo: 55 segundos.

## 0 a 8 segundos

**Pantalla:** portada de AgendaUPC.

**Narración:** “Los estudiantes reciben tareas de varios cursos y pueden perder fechas límite. AgendaUPC reúne esos pendientes en una sola vista.”

## 8 a 22 segundos

**Pantalla:** botón **Nueva tarea** y formulario.

**Narración:** “La aplicación permite registrar una tarea con su curso, fecha, prioridad, horas estimadas y notas. Los datos se guardan automáticamente en el navegador.”

## 22 a 37 segundos

**Pantalla:** panel con datos de ejemplo; mostrar filtros y búsqueda.

**Narración:** “El panel muestra tareas próximas, vencidas, progreso y carga pendiente. También puedo buscar y filtrar por estado o prioridad para concentrarme en lo urgente.”

## 37 a 47 segundos

**Pantalla:** completar una tarea y mostrar exportación.

**Narración:** “Al completar una tarea, los indicadores se actualizan. Además, puedo exportar un respaldo en JSON e importarlo después.”

## 47 a 55 segundos

**Pantalla:** Visual Studio Code con Copilot Chat y terminal de pruebas.

**Narración:** “GitHub Copilot apoyó el análisis, la revisión de fechas, la refactorización y las pruebas. Yo revisé cada sugerencia y validé el resultado antes de incorporarlo.”

## Recomendaciones de grabación

- Use una resolución legible y aumente el zoom si el texto es pequeño.
- Prepare los datos de ejemplo antes de grabar.
- Mantenga visible la URL pública de GitHub Pages al inicio o al final.
- Muestre al menos una interacción real de Copilot y la salida de las pruebas.
- Exporte el video con acceso público o mediante enlace habilitado para revisión.
